# Development documents

Working documents for building Bridge. User-facing documentation is the VitePress site under `docs/` (`pnpm docs:dev`).

- `propmts.md` — the original design brief (filename typo preserved deliberately; it is referenced elsewhere). Source of truth for requirements.
- `PLAN.md` — the technical implementation plan and the architectural source of truth, including implementation notes that record every deviation.
- `security-review.md` — the review of the plan's security section against the implementation, with evidence per control.
- `relay-design.md` — design for an external stream relay (not implemented).
- `release-readiness.md` — the Definition of Done status and the steps to cut a release.
