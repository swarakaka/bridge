# Changesets

npm packages (`@swarakaka/bridge-protocol`, `@swarakaka/bridge-core`, `@swarakaka/bridge-vue`) are versioned together with [changesets](https://github.com/changesets/changesets). Run `pnpm changeset` in a PR that changes a package. The Laravel package (`swarakaka/bridge-laravel`) is versioned by git tag `laravel-vX.Y.Z` and its changelog lives in `CHANGELOG.md`.
