## Residual risks and recommendations

- **CDNs that ignore `Vary`** can serve a JSON representation to a browser for public pages. Keep public caching opt-in (default) and key CDN caches on `Accept` when enabling it.
- **Data-carrying stream events** (`prop`, application events) bypass request-time authorization. Publish them only to per-user or per-tenant channels; use `invalidate` for anything else. The playground follows this rule.
- **Ticket URLs in logs.** Tickets expire in 60 s, but access logs still record them. Treat log access as sensitive or shorten `ticket_ttl_s`.
- **Database bus growth.** Schedule `bridge:stream:prune`.
- The Redis driver's cross-channel replay is approximate at millisecond granularity (documented in PLAN §20.2 notes).
